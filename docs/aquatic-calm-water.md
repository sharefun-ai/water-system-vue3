# AQUATIC 清水首頁 · 3.11.6

首頁使用整片即時渲染的平靜清水。新版移除容易像漂浮物的獨立橢圓光斑，改用互相連接、隨水面彎曲的細緻光紋，配合更通透的清藍色與柔和天空反射。

## 渲染

- `calmWater.js` 保留六組細小法線水波。底層光紋使用緩慢移動的鄰近聚光位置，在二者交界形成連續光網；空間扭曲讓細線自然彎曲，疏密和亮度逐漸變化，不再以曲率零值形成孤立橢圓輪廓。
- 柔和光帶與較細的光芯以有界函數繪製，配合局部淡化保留清水的留白。這是品牌視覺的焦散近似，不是完整光線追蹤。
- `waterField.js` 使用現有互動高度場改變水面法線與焦散取樣位置。滑鼠、觸控、開場水滴使用同一個波場，讓光紋與互動波紋融入同一片水。
- 字樣與水滴的透射色也改為取樣新的清水底層，保留先前的水滴慢動作、光學邊緣、文字局部折射與逐步消融。
- 首頁水面不依賴背景照片下載；水面材質與字樣完成第一幀後才開始淡入。預渲染底色改為對應的清水漸層。
- Canvas 降級使用相同光網與色彩公式即時計算低解析畫面；每幀快取聚光位置，減少重複運算，再放大繪製。
- 沿用效能預算、減少動態偏好、視窗隱藏暫停、聲音須互動啟動與卸載清理。

## 驗證

- 47 項雲端專案測試通過。水光在多種畫面比例和長時間下保持有限、無 NaN；沒有輸入時仍連續流動。
- 實際瀏覽器確認 WebGL 可渲染、新水面與開場字樣／水滴共存、互動波紋改變背景光紋。
- 暫停後渲染幀與水面時間均保持不變；恢復後繼續流動。
- 公開驗證截圖：`docs/screenshots/aquatic-clear-*.jpg`。
