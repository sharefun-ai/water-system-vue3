# AQUATIC 清水首頁 · 3.11.5

首頁移除 `ocean-depth.webp` 海浪照片，改為整片即時渲染的平靜清水。以深藍、玉青的透水色、緩慢流動的焦散光紋、柔和天空反射呈現乾淨、永續的水感。

## 渲染

- `calmWater.js` 定義六組細小水波與緩慢空間扭曲。波向與頻率避免規則重複，水面自然持續流動，不依賴滑鼠輸入或預錄影像。
- 由波面曲率近似折射光線映射的 Jacobian，計算水下明暗聚光；有限光源寬度限制焦散峰值。這是品牌視覺的即時近似，不是完整光線追蹤。
- `waterField.js` 使用現有互動高度場改變水面法線與焦散取樣位置。滑鼠、觸控、開場水滴使用同一個波場，讓光紋與互動波紋融入同一片水。
- 字樣與水滴的透射色也改為取樣新的清水底層，保留先前的水滴慢動作、光學邊緣、文字局部折射與逐步消融。
- 首頁水面不依賴背景照片下載；水面材質與字樣完成第一幀後才開始淡入。預渲染底色改為對應的清水漸層。
- Canvas 降級使用相同水波參數即時計算低解析光紋，再放大繪製，亦不再使用海浪照片。
- 沿用效能預算、減少動態偏好、視窗隱藏暫停、聲音須互動啟動與卸載清理。

## 驗證

- 47 項雲端專案測試通過。新增光學聚焦在多種畫面比例和長時間下保持有限、無 NaN 的測試，以及沒有輸入時仍連續流動的測試。
- 實際瀏覽器確認 WebGL 可渲染、新水面與開場字樣／水滴共存、互動波紋改變背景光紋。
- 暫停後渲染幀與水面時間均保持不變；恢復後繼續流動。
- 後续公開驗證截圖：`docs/screenshots/aquatic-calm-*.jpg`。

本次只替換首頁的水面與共用於其開場的取樣；資料介面與其他頁面維持現有設計。
