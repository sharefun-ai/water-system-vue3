# AQUATIC 開場水波折射 · 3.11.4

## 行為

- 移除載入前立即顯示的 SVG 字樣。背景紋理完成下載並通過第一幀渲染後，才讓唯一一份 WebGL 字樣由透明漸入。資源等待期間開場時鐘停在零；離開頁面會取消就緒回呼。
- 移除每個字母的旋轉與彈簧平移。每個像素直接取用水面波動模擬的高度、坡度，产生局部折射、筆畫彎曲與光澤變化。字樣與海面使用同一個場，滑鼠、觸控和開場水滴都向同一個模擬注入擾動。
- 字樣仍由中心向外逐步消融。位移以平滑上限保持可讀性；系統減少動態偏好會降低強度。
- 水滴改為持續變形的細長滴體，上肩收窄、下部圓潤，慢動作期間略微回縮，撞擊前再次拉伸。
- 折射使用變形滴體的表面法線，沿折射光線尋找第二個介面。菲涅耳反射、邊緣弧光與內部焦散全部限制在滴體遮罩內；移除外部光束和離水滴很遠的光點。
- 開場水面亦可點擊、拖曳；音效仍須真實使用者操作才啟動。略過、頁面切換不重播與現有入口維持可用。

本效果是為品牌開場設計的即時光學近似，不是流體體積或精確光線追蹤。
