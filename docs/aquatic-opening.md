# AQUATIC 水滴開場 — 3.11.2

2026-10-04，Asia/Taipei。首頁首次進入時，以水滴、波紋和 AQUATIC 字樣展示品牌；手機約 5 秒、桌面約 7 秒。首頁的原有水面與四個功能入口沿用。

- `src/brand/waterIntro.js`：手工幾何字形，SVG 載入佔位與 WebGL 字紋共用同一套路徑。字紋在本機以 Canvas 產生，不載入外部字型或圖片。
- `src/brand/waterField.js`：字樣先浮現，玻璃水滴加速落下，在 2.35 秒注入原有 GPU 波場。折射、藍光與文字沖散使用同一個擴散速度，波紋由中央向外使字形扭動、化為微光並消退。
- 開場與互動水面在同一個 renderer / canvas 上繪製；結束時直接繼續流動，不重新掛載水面。字紋貼圖在完成／略過／離開頁面時釋放。
- 進入時只顯示字樣、水滴與低調略過入口，結束後才淡入功能選單。略過後焦點交還互動水面。進入功能頁再返回首頁不重播；重新載入網站會再次播放。
- 不自行啟動聲音。第一次真實點水或開啟聲音時沿用原本旋律。頁面隱藏時暫停繪製；減少動態設定會降低折射位移與光量，環境水流沿用慢速。
- WebGL 無法建立时，原有 Canvas fallback 同樣畫出字樣、水滴與波紋消散；模組無法載入時仍可略過並使用功能入口。

驗證：正式 build 成功，原有 40 項測試通過；本機實際 WebGL 字樣、水滴、擴散與完成狀態可見。390 × 844 手機無水平溢出，略過恢復四個功能入口。開場後暫停、再次點水恢復與音效啟動均通過。公開網站的實際截圖保存在 docs/screenshots。
