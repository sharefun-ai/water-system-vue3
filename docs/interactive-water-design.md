修改專案：`C:\xampp\htdocs\水系統3.0\Water System 3D SCADA`。首頁：`dist/#/portal`。

依本次要求，首頁以整片可互動的水取代製程影片。畫面只保留 AQUATIC、四個功能入口、聲音與暫停控制；第一次互動後淡出「觸碰水面」提示。

參考：[cantouchthis.studio 的水、聲音與光互動](https://www.instagram.com/reel/Dbk954IMrW0/)。已在 Chrome 觀看參考；沒有下載影片或使用其中的音樂、影像。底圖沿用專案既有的 `src/assets/ocean-depth.webp`，聲音以本機 Web Audio 原創合成。

## 水面與資訊

- `src/brand/waterField.js` 使用 Three.js 全畫面著色器；可用浮點 render target 時，以兩張半浮點高度圖交替計算離散波方程，保存現在與上一刻的高度。輸入以局部水面擾動注入，多個波紋共享波場並產生交疊。
- 高度梯度同時改變水面法線、底圖折射、反射與局部藍光。水光與資訊喚醒使用相同的傳播速度，緩慢擴散和消退。
- 資訊節點與連線沿用 `topology.js` 的 35 個設備／24 個管段座標，轉為水下低對比的抽象資訊流。它們是藝術表現，不代表即時 PLC 狀態、實測水流或控制命令。
- 滑鼠點擊與拖曳、觸控和 Enter／空白鍵都可觸發；滑鼠輕移產生無聲的細小擾動。點擊已暫停的水面會恢復；滑鼠移入不會自行取消暫停。
- 不支援浮點高度圖時使用 WebGL 解析波紋；WebGL 無法建立時使用 2D Canvas 水面與波光。資源失效時頁面仍保留水圖與功能入口。

## 聲音與操作

- `src/brand/waterSound.js`：D 大調五聲音階，點擊位置選擇音高與左右聲像。柔和正弦基音、少量泛音、自製混響和限幅，搭配緩慢交錯旋律。
- 頁面載入保持無聲；第一次真實點擊／觸控／鍵盤互動，或點選聲音按鈕後，才建立並啟動 AudioContext。滑鼠移動不啟動聲音。
- 聲音可靜音／重新開啟；暫停水面同時暫停聲音。頁面隱藏時停止動畫、旋律排程與聲音，恢復後續播；離開首頁關閉 AudioContext 與所有首頁計時器。
- 四個入口保留原路由；離開首頁使用柔和淡出。原有圖控、趨勢、警報、報表與共用海面邏輯沿用。

## 效能與驗證

- 桌面約 30 FPS、手機與減少動態約 20 FPS；畫布最高 160 萬畫素，高度圖最多約 448 × 256。背景隱藏／離開可見範圍停止繪製。
- 系統減少動態時，環境流動降速；主動觸碰的水波仍可互動。保留鍵盤焦點、44 px 觸控控制及手機二欄／橫向單列入口。
- 渲染器、波圖、材質、幾何、貼圖、ResizeObserver、IntersectionObserver、事件與音效排程在卸載時釋放。
