# AQUATIC 液態字樣、日光水滴 — 3.11.3

2026-10-04，Asia/Taipei。延伸 3.11.2 片頭：將字樣改為可折射海面的水體材質，水滴改成圓潤的透明水珠，下降途中加入 0.9 秒慢動作，落水後先晃動、回彈，再消散。

- 字樣：同一組幾何路徑烘焙成圓弧高度圖，以高度梯度取得表面法線。著色器對海面進行局部折射，搭配 Fresnel 反射、日光亮點和濕潤邊緣。載入時的 SVG 使用一致的粗細與版面。
- 水滴：前／後兩個曲面界面計算折射方向（近似水的 IOR 1.333）；內部呈現折射後的既有海面，邊緣反射天空，右上方有日光高光、微弱光暈及下方聚光。沒有外部影片或新增底圖。
- 慢動作：1.85–2.75 秒，以連續位置及速度的 Hermite 曲線放慢落水動作，再恢復速度；3.55 秒注入原有 GPU 波場，整段約 7–9 秒。移入／點擊水面原有互動與聲音規則沿用。
- 文字受力：各字依離落水點的距離，在波紋到達時開始阻尼擺動、微幅旋轉和局部變形。保留約 0.9 秒回彈時間後，才隨後續波紋逐漸消散。回彈是視覺物理模型，不是完整流體力學求解。
- 沿用同一張畫布與 renderer，字紋完成後釋放；只在可見、未暫停的頁面繪製，完成後恢復原本海面。手機、略過、返回首頁不重播、減少動態時降低位移與亮度沿用。
- 渲染器不支援 WebGL 時，Canvas 版同步使用相同下落時間和慢動作曲線，提供簡化的水珠光澤及文字擺動。

43 項測試通過，其中新增下落位置／速度連續性、慢動作速度和不同長寬比的文字回彈時間檢查。片頭光澤、波紋與手機呈現另以實際瀏覽器驗證。
